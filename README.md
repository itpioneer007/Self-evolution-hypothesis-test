# Solingo 出题工作台

面向小学英语教材的自适应出题与验证工具。同一轮里由模型规划考点、逐题出题、独立质检，学生作答后错题进入错题本，下一轮按错题重新出题——形成一个可以自己往前走的闭环。

零依赖、零构建，双击 `index.html` 即可运行。

---

## 它解决什么问题

常规出题器只解决「题对不对」，证明不了「学生会不会」。这中间缺三样东西：

1. **题不一样**——5 道题不能全是同一考点的同一种问法；
2. **判得动**——模型出的题要能被自动判定通过与否，不能全靠人；
3. **记得住**——这一轮错过的考点，下一轮要能自己找回来。

这个工具把这三件事落成可运行、可复算的代码，并用最小规模（一个单元、两轮）验证链路是否成立。

---

## 核心特性

- **三个角色，一个模型**：规划 / 生成 / 质检各自独立的提示词与记忆，互不共享上下文。生成方看不到学生画像（防止不自觉降难度），质检方也看不到（防止同情放水）。
- **代码闸有通过权，模型只有否决权**：八条可复算的硬判据（超纲、答案在选项、选项互异、题干泄题、解析空话、听力音文一致、归属合法、同轮不同格）决定一道题能不能进；模型质检只能挑错、不能放行。
- **格子由代码分配**：模型只提「这一轮考什么」，四维格子（题型 × 场景 × 层次 × 错项类型）由代码分配，防止五道题长成一个样，也保证结果可复算。
- **失败全量留痕**：被退回的题记下阶段、条款号、原因、第几次，原因回灌进下一次生成提示词；被放弃的考点进重试队列，下一轮换个角度补上。
- **跨轮错题回练**：这一轮答错 → 当场进错题本 → 下一轮由模型按「同考点、换题面、换答案」重新出题，而不是当轮补一道代码拼出来的固定变体。
- **三本教材真数据**：人教 PEP、冀教版、湘少版四年级上册，词表、句型、语音点、情境域按单元切片，换册时五样边界一起换。

## 快速开始

### 环境

- 浏览器：Chrome / Edge 等现代浏览器
- Node.js **18+**（仅用于跑测试脚本，页面本身不需要）

### 打开

**方式一（推荐）**：直接双击 `index.html`。DeepSeek 接口对 `file://` 返回 `access-control-allow-origin: null`，可以直连。

**方式二**：起静态服务器（个别浏览器对 `file://` 的 localStorage 策略不同，刷新后数据丢失时用这个）：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

### 配置模型

点击顶栏右上角 **「模型」**，填入：

| 字段 | 默认值 | 说明 |
|---|---|---|
| 接口地址 | `https://api.deepseek.com` | 兼容 OpenAI `chat/completions` 协议 |
| 模型 | `deepseek-chat` | |
| API Key | 空 | 只存本机 localStorage，不落盘、不进仓库、导出 JSON 会剔除 |

填完直接点「测试连通性」即可，无需先保存。成功会显示模型名与耗时，失败会显示错误类型（`auth` / `timeout` / `rate` 等）。

### 跑一轮

1. 在 01 页勾选「纳入」几个考点，确定这一轮的范围；
2. 点「模型出 5 题」，等待 20–70 秒；
3. 切到 02 页作答，每题选一个选项 → 「提交」→「下一步」；
4. 切到 03 页看错题是否写入；
5. 回 01 页点「进入第 2 轮」→「模型出 5 题」，此时上一轮错过的考点会由模型重新出题。

## 四个页签

| 页签 | 作用 |
|---|---|
| **01 出题** | 三个智能体卡片（课程 / 执行 / 验证），一次只显示一个角色。上方是配额条（七类能力各出几题），中间是计划表，下方是失败记录入口 |
| **02 答题** | 学生侧。题干、选项、提交、提示；答错当场说明会写进错题 |
| **03 错题** | 错题本。每条带原题快照、作答与正确答案、错因、教材依据；可「写入计划」带回 01 |
| **04 日志** | 出题日志（带时间与轮次、按状态着色）、没出成的题（按考点分组、按时间排序）、KPI 与停止决策 |

停止有两个信号：**SATURATED**（本轮考点全部真会且不少于 3 个）、**STALLED**（不少于 2 个考点连续过不了闸）。判出来会自动填进停止条并附依据，依据可改。

## 工作原理

### 流水线

```
规划（模型提考点）
  → 代码校验：范围 / 层次上限 / 已退役 / 能力配额 / 考点去重
  → 代码分格（四维，模型不参与）
  → 逐题生成（模型）
  → 代码闸 V1–V8（不过就带原因重出，最多 3 次）
  → 独立质检（模型，只能否决）
  → 通过则落库；仍不过则记 GIVE_UP
```

### 判题权限

| 角色 | 权力 | 理由 |
|---|---|---|
| 代码闸 `validateQuestion` | **通过权** | 可复算、可回归。它说不过，一定不过 |
| 模型质检 `AGENTS.verify` | **否决权** | 说挂才退回；说通过不算数，仍要过代码闸 |

这个不对称是刻意的：生成方和质检方是同一个模型的两套配置，给质检通过权等于让模型给自己判卷。代价是代码闸的误判会直接吃掉题，因此每条判据的误杀都要能被回归测试复现。

### 跨轮错题回练

| 步骤 | 发生位置 |
|---|---|
| 答错 → 写进 03 错题 | 02 页「下一步」 |
| 错题进 `priority`，带上考点 id 与上一轮原题题干 | 下一轮 `buildBrief` |
| 命中错题的考点被标记为 `probe` | 流水线（代码标记，不让模型自己声明） |
| 按「同考点、同层次，换场景与问法，换答案」重出 | 生成角色 |
| 回练结果写回错题本，连对两次才算「已掌握」 | 02 页「下一步」 |

一次答对只到「已订正」：可能是蒙对，也可能只是记住了上一轮那道题。

### 考点推进

每个考点按 **认 → 辨 → 用 → 表达** 升层。真会升一层，答错降一层；到顶层且已经会过两次就退役，不再排题。学生分层决定层次上限（A 到表达、B 到用、C 到辨），模型给出的层次超过上限会被代码压回去并留痕。

## 教材与数据

三本四年级上册教材，按单元切片。切换教材或单元时，词表、句型表、语音点、情境域、功能词白名单五样一起换。

| 教材 | 单元 | 词条 | 说明 |
|---|---|---|---|
| 人教 PEP 四上 | 6 | 104 | 唯一入库了候选知识点清单（U1 有 8 条） |
| 冀教版 四上 | 4 | 77 | 无语音板块 |
| 湘少版 四上 | 12 | 89 | 书后词表是图片，取词自正文，超纲边界更窄 |

数据来自 [English Anchor 教材目录](https://englishanchor.online/downloads/textbooks/) 提供的公开镜像，用 PyMuPDF 抽取文本层后按单元整理。**没有文本层的扫描版不入库**（沪教版、外研社陈琳版四上经检查为 0 字符，已排除）。音标在原 PDF 里是嵌入字体，抽出来是乱码，因此不收。

## 开发与测试

```bash
# 主回归：不需要 key、不需要浏览器
node tools/smoke-test.js

# 浏览器端到端：本地 mock 模型 + 无头 Edge，验 fetch / JSON / 事件回调 / 按钮接线
node tools/e2e-browser.js

# 真模型全链路（两轮，含错题回练）
DEEPSEEK_API_KEY=sk-xxx node tools/live-run.js

# 真实点选界面（勾范围 → 出题 → 作答 → 错题 → 第二轮）
DEEPSEEK_API_KEY=sk-xxx node tools/ui-check.js
```

当前状态：`smoke-test` **208 项全绿**，`e2e-browser` **8 项全绿**。

新增判据请同时补断言。这个项目里反复出现过同一类问题——判据自己误判却看起来像模型出错（例如把占位符当成超纲词、把 `nears` 当成没学过的词），只有断言能拦住回归。

## 合并回主仓

`src/core/` 下所有模块都是纯函数、无 DOM 依赖，改成 `.ts` 加导出即可直接搬；`src/app.js` 是唯一的渲染层，换成 React 组件。

一处必须改：主仓的学生数据只能走 `StudentWorkspace` + zustand persist（key `solingo-store-v3`），页面禁止直接访问 localStorage。本项目的 `sht-minimal-test-v2` 需要替换掉。

## 已知边界

- **5 题 2 轮只够看方向**，不足以证明效果。要证明至少需要 1 个班、3 个单元、纵向 4 周。
- **通过率会抖**：配额每类 1 条时没有冗余，一格失败就少一题。同一批考点有时 4 道全出，有时只出 2 道。
- **「答案唯一」判不了**：代码无法二元判定 `It's ___ the wall` 填 `near` 是否也通顺，只能靠模型质检，模型三轮改不好就放弃那一格。
- **解析长度与解释深度有张力**：解析超过 30 字判不过、超过 25 字给警告，而逐项罗列每个错项本身就写不下。现在靠软否决（只指向解析的否决不废题，标为待润色）绕过去，不是治本。
- **判对错是字符串比对**，不是语法判定。大小写与句末标点已归一化，措辞不同但意思相同的答案判不了。
- **口语题接不出回练**：需要语音证据，选项框判不出来。
