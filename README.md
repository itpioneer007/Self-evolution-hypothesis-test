# Self-evolution hypothesis test

最小出题测试工作台。用一个学生、一个单元、五道题、跑两轮，验证「规划 → 生成 → 质检 → 记忆库 → 组卷与停止」这条链能不能让题**不一样**而且**对学生有用**。

这是实验用的界面模板，不是产品页面，也不是自动出题器。

---

## 为什么是零依赖的静态页面

主仓 `D:/vscode/Solingo-main` 是 Vite 5 + React 18 + TypeScript + Tailwind 3 + Zustand。这个模板刻意**没有**照搬构建链，理由是成本：为了跑五道手工题去装一整套依赖、起五个 companion 服务、配 API Key，与「最小验证」的目的相悖。

保持了与主仓一致的是**数据契约和领域逻辑**，不是构建工具：

- 教材词表、句型表、话题域直接取自 `public/quiz/data.js` 的 U1 原文
- 题型、七类能力、知识点 id 口径对齐 `quizAssessment.ts` / `personalization.ts`
- 指纹算法沿用 `questionIdentity.ts` 的 FNV-1a 思路，改成按「变化轴四维」判重（要防的是多样性坍塌，不是题干重复）
- 四层检查表、八条清单、五阶段、自检十问来自同目录外的三份规范文件

逐条对应关系见 [`docs/SOURCE-MAP.md`](docs/SOURCE-MAP.md)。要并回主仓时，`src/core/` 三个文件都是无 DOM 依赖的纯函数，改成 `.ts` 加导出即可；`src/app.js` 的渲染层换成 React 组件，照 `src/pages/assessment/index.tsx` 的题型渲染骨架改写。

## 怎么跑

**方式一（推荐）**：直接双击 `index.html`。零依赖、零构建、离线可用。

**方式二**：起个静态服务器（浏览器对 `file://` 的 localStorage 策略不同，若发现刷新后数据丢失就用这个）：

```bash
cd Self-evolution-hypothesis-test
python -m http.server 8080
# 打开 http://localhost:8080
```

数据只写浏览器 localStorage（key `sht-minimal-test-v1`），不上传、不接后端、不调模型。页面右下角有「重置」。

## 界面三列

| 列 | 对应环节 | 干什么 |
|---|---|---|
| 左：命题规划 | 课程智能体 | 5 行配额表。每行指定知识点与**格子**（题型 / 情境 / 考查层次 / 干扰项类型）。第 2 轮会标出与历史撞格子的题 |
| 中：题目生成 | 执行智能体 | 单题九字段编辑、单元词表条。一次只出一题 |
| 右：独立质检 | 验证智能体 | 四层 23 条逐条点「过 / 挂」，挂了的条款号自动进退回清单 |

底栏是环节 4（记忆库）与环节 5（组卷与停止）的结果：格子重合率、两轮退回趋势、是否提前结束，以及导出记录 JSON。

**自动化边界要说清楚**：界面只自动做三件事——分配不重复格子、记录检查结果、算三个指标。**题目内容由人按格子填写**。这符合最小测试「全手工」的口径，也避免让模型自由出题带来超纲和答案不唯一。

---

## 最小测试怎么跑

1. 第 1 轮：核对示例 5 题（或清空自己出），逐题在右列过 23 条检查，挂了的写清楚条款号。
2. 点「结束本轮，进入第 2 轮」。界面会先查记忆库，自动排除第 1 轮用过的格子，保留同一批知识点，把题目内容清空等你按新格子重出。
3. 第 2 轮：按新格子出题，再过一遍检查。
4. 看底栏三个指标，导出 JSON 对照规范文件里的 `最小测试记录表.md` 写结论。

三个判定指标：

| 指标 | 合格线 | 不达标说明什么 |
|---|---|---|
| 格子重合率 | ≤ 1/5 | ≥ 3/5 说明变化轴没起作用，问题在环节 1 或记忆库没前置 |
| 两轮退回趋势 | 第 2 轮低于第 1 轮 | 不降说明退回原因码没被用上 |
| 是否提前结束 | 至少出现一次有依据的提前结束 | 两轮都凑满 5 道，说明停止判据没落地 |

完整规程见 [`docs/SPEC.md`](docs/SPEC.md)。

## 示例数据说明

`src/data/curriculum.js` 里的 5 道示例题全部用 U1 真实词句，且刻意落在 5 个不同格子。它们是**模板**，不是标准答案。

一处真实约束也保留在界面里：U1 话题域是 Our School，情境维度实际只开放「学校」。硬要换到「家庭」「交通」就会引入单元外词汇，直接变超纲题。这正是规范文件里「格子会撞完」那条风险的实例——理论上有 9 × 10 × 4 × 6 个格子，落到具体单元只剩几十个可用。

## 已知边界

- 5 题 2 轮只够看方向，不能证明效果。要证明至少需要 1 个班、3 个单元、纵向 4 周。
- 八条清单里的「答案唯一」在中文释义题里无法二元判定，必须人看。界面不假装能自动判。
- 停止阈值「连续三次全对」尚未校准。
- 本模板不接 AI 服务。主仓 `/api/ai/analyze` 的 `trainingQuestions` 可以出 3 道题，但按现有立场，AI 只放在「讲错题」这类容错高的位置。
