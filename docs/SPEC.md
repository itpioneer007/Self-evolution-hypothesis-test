# 最小出题测试规程

> 本文件是 `../Solingo出题RSI/出题手册.md` 第 5 节的自包含精简版，供脱离工作区使用本仓库时照做。

## 规模

| 项 | 值 |
|---|---|
| 学生 | 1 个（有作答记录和错题） |
| 教材 | 1 册（人教版 PEP 四年级上册，6 个教学单元，见 `src/data/textbook.js`） |
| 单元 | 1 个（词表 + 句型表 + 语音点齐全；顶栏切到哪个单元就只跑哪个单元） |
| 题量 | 5 道 |
| 轮次 | **2 轮**（只跑一轮验证不了「不一样」） |
| 方式 | 全手工，不调模型 |

前置：确认顶栏选中的单元就是要测的那个。教材已整册入库（`src/data/textbook.js`），词表 / 句型表 / 语音点 / 情境域随单元自动切换；示例错题由该单元候选里的真实错例生成（`SHT.buildWrongCases(unitId)`，每单元 3 条）。正式测试要换成真实学生的错题。

## 界面与规程的对应

| Tab | 覆盖本规程的哪几步 |
|---|---|
| 01 出题 | 第 1–3 步。左侧三个智能体卡片切换：课程智能体写计划、执行智能体逐题生成、验证智能体逐层过 23 条 |
| 02 答题 | 第 3.5 步（作答与变体）：学生逐题作答 → 判对错 → 对就换考点 / 错就换一道同考点的变体 → 还错写错题 |
| 03 错题 | 学生侧回边：错因 → 出题要点 → 点「写入计划」回填第 1 步 |
| 04 日志 | 第 4–5 步与第 8 步：出题日志（含每题的作答）、打回缘由分布、已占用角度、停止决策 |

## 第一轮

1. **01 / 课程智能体**：写计划，5 行，每行指定知识点与出题角度（题型 / 场景 / 考查层次 / 错项类型）。可点「排 5 个角度」或「按薄弱点填」。
2. **01 / 执行智能体**：逐题生成，一次一道，不批量。
3. **01 / 验证智能体**：逐题过四层 23 条检查，一次显示一层，记下挂在哪一条、怎么改。
4. **03 / 日志**：通过的题与退回的题（带条款号）自动进日志，人工核对。
5. **03 / 停止决策**：标出是否可以提前结束，勾「会了 / 卡住」并写依据。

## 第 3.5 步：作答与变体（02 答题）

出题合规只说明题对了，不说明他会不会。每个考点打两枪：

| 情况 | 动作 | 记什么 |
|---|---|---|
| 原题答对 | 换下一个考点 | 会用 |
| 原题答错 | 换一道**同考点、换掉表面**的变体再问 | 暂记不会 |
| 变体答对 | 换下一个考点 | 原题也对过 → 真会；原题错过 → 换个角度才会 |
| 变体也答错 | 写进 03 错题，换下一个考点 | 不会 |
| 原题对、变体错 | —— | 只记住这道题 |
| 任一枪用了提示 | —— | 最高「看提示才会」，不算真会 |

变体与出题的判据是反的：出题要**换格子**（防 diversity collapse），变体要**同格子换表面**（防背题）。变体不进去重台账，也不算出题产量。

变体由 `SHT.buildVariant()` 按题型从本单元教材数据确定性派生：听音选义/中英匹配换词、拼写换词并生成错拼、辨音换 `phonics.pairs`、选词填空/句子判断挖句型表里的位置介词、对话补全换句型表问答。接不出来（看图说词、个别单元的选词填空）时不硬编，直接记错题，卡片会写明。

写错题的时机只有两个：变体也错、接不出变体。首次作答冻结进 `firstAttemptEvidence`，变体那枪写进 `errorCause`；同一考点只留一条错题案。

## 第二轮

6. 重新规划，**先看 03 的已占用角度**：同角度不能再用；同知识点同类题累计不超过 2 次。
7. 重复第 2–5 步。
8. 对比两轮，看 KPI「角度重复」（规范里叫格子重合率）。

界面已把第 6 步自动化：点「进入第 2 轮」会避开上轮用过的角度、保留知识点、清空题目内容，并跳回 01 的课程智能体。

## 三个判定指标

| 指标 | 算法 | 合格线 | 不达标说明什么 |
|---|---|---|---|
| 格子重合率（界面：两轮出题角度重复了几道） | 第 2 轮与第 1 轮完全同格子的题数 ÷ 5 | ≤ 1/5 | ≥ 3/5：变化轴没起作用，问题在环节 1 或记忆库没前置 |
| 退回率与条款分布 | 退回数 ÷ 5，以及挂在第几条 | 第 1 轮预期 2–3 道；第 2 轮应降到 1 道左右 | 第 2 轮不低于第 1 轮：原因码没被用上 |
| 是否提前结束 | 勾选 SATURATED / STALLED 且填写停止依据，两者缺一不算 | 至少一次有依据的提前结束 | 两轮都凑满 5 道：停止判据没落地 |

**诚实边界**：5 题 2 轮只够看方向，不能证明效果。要证明至少需要 1 个班、3 个单元、纵向 4 周。

## 跑完对照三类失效

| 失效 | 在出题里的样子 | 自查 |
|---|---|---|
| self-confirming loop | 因为「生成方说条件无冗余」就放行 | 有没有哪道题是凭自述过的 |
| collapse | 第 2 轮把第 1 轮换了个数字或选项顺序 | 按口径这不算新题 |
| diversity collapse | 5 道题全落在「听音选义 + 同类不同物 + 认」 | 收敛到了最省力的题带 |

## 结论写法

只写一句：这套流程在本次测试中（成立 / 部分成立 / 不成立），主要证据是三个指标的数值。不写感受，不写「效果明显」。

导出的 JSON 字段与本规程一一对应（`indicators` / `practice.round1|round2` / `weaknessProjection` / `wrongCases` / `rounds`），可直接贴进 `../Solingo出题RSI/最小测试记录表.md` 的第 3 节。改完代码跑 `node tools/smoke-test.js` 自检。
