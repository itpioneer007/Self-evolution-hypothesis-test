# 最小出题测试规程

> 本文件是 `../Solingo出题RSI/出题手册.md` 第 5 节的自包含精简版，供脱离工作区使用本仓库时照做。

## 规模

| 项 | 值 |
|---|---|
| 学生 | 1 个（有作答记录和错题） |
| 单元 | 1 个（词表 + 句型表齐全，本模板固定 U1） |
| 题量 | 5 道 |
| 轮次 | **2 轮**（只跑一轮验证不了「不一样」） |
| 方式 | 全手工，不调模型 |

前置：把该单元词表、句型表、这个学生近三次练习的错题抄进一个文档。词表在 `src/data/curriculum.js`；错题案在 `src/data/wrongCases.js`（3 条示例，对齐 `sampleStudent.recentErrors`），正式测试要换成真实学生的。

## 界面与规程的对应

| Tab | 覆盖本规程的哪几步 |
|---|---|
| 01 三个智能体 | 第 1–3 步。课程智能体写配额、执行智能体逐题生成、验证智能体逐层过 23 条 |
| 02 错题记录 | 学生侧回边：作答 → 错因 → 薄弱画像 → 回填第 1 步的依据栏 |
| 03 记忆库与停止 | 第 4–5 步，以及第 8 步的两轮对比 |

## 第一轮

1. **Tab 1 / 课程智能体**：写配额表，5 行，每行指定知识点、格子（题型 / 情境 / 层次 / 干扰项类型）、难度。可点「取薄弱画像前 3 条」把 Tab 2 的结果直接写进依据栏。
2. **Tab 1 / 执行智能体**：逐题生成，一次一道，不批量。
3. **Tab 1 / 验证智能体**：逐题过四层 23 条检查，一次显示一层，记下挂在哪一条、怎么改。
4. **Tab 3 / 记忆库**：把通过的题、退回的题（带条款号）都写进记忆库。界面自动汇总，人工核对。
5. **Tab 3 / 停止决策**：标出是否可以提前结束，勾 SATURATED / STALLED 并写理由。

## 第二轮

6. 重新规划，**先查第一轮的记忆库**：同格子不能再用；同知识点同类题累计不超过 2 次。
7. 重复第 2–5 步。
8. 对比两轮，算格子重合率。

界面已把第 6 步自动化：点「结束本轮，进入第 2 轮」会排除历史格子、保留知识点、清空题目内容，并自动跳回 Tab 1 的课程智能体。

## 三个判定指标

| 指标 | 算法 | 合格线 | 不达标说明什么 |
|---|---|---|---|
| 格子重合率 | 第 2 轮与第 1 轮完全同格子的题数 ÷ 5 | ≤ 1/5 | ≥ 3/5：变化轴没起作用，问题在环节 1 或记忆库没前置 |
| 退回率与条款分布 | 退回数 ÷ 5，以及挂在第几条 | 第 1 轮预期 2–3 道；第 2 轮应降到 1 道左右 | 第 2 轮不低于第 1 轮：原因码没被用上 |
| 是否提前结束 | 勾选 SATURATED / STALLED 且填写停止依据，两者缺一不算 | 至少一次有依据的提前结束 | 两轮都凑满 5 道：停止判据没落地 |

**诚实边界**：5 题 2 轮只够看方向，不能证明效果。要证明至少需要 1 个班、3 个单元、纵向 4 周。

## 跑完对照三类失效

| 失效 | 在出题里的样子 | 自查 |
|---|---|---|
| self-confirming loop | 因为「生成方说条件无冗余」就放行 | 有没有哪道题是凭自述过的 |
| collapse | 第 2 轮把第 1 轮换了个数字或选项顺序 | 按口径这不算新题 |
| diversity collapse | 5 道题全落在「听音选义 + 同类不同物 + 认」 | 收敛到了最省力的题带 |

## 结论写法

只写一句：这套流程在本次测试中（成立 / 部分成立 / 不成立），主要证据是三个指标的数值。不写感受，不写「效果明显」。

导出的 JSON 字段与本规程一一对应（`indicators` / `weaknessProjection` / `wrongCases` / `rounds`），可直接贴进 `../Solingo出题RSI/最小测试记录表.md` 的第 3 节。改完代码跑 `node tools/smoke-test.js` 自检。
